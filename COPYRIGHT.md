# Copyright and use status

All rights reserved. **No license to use, copy, modify, or distribute this
software is granted.**

The source is publicly readable so that the maintainer's own agents and tools
can work with it, and so that issues can be discussed in the open. Public
visibility is not a grant of permission — the absence of a `LICENSE` file here
is a deliberate decision, not an omission.

## Why

This SDK is a client for a **private** Gravity API. Licensing the client to the
public would imply an authorization to reach that API which this repository has
no standing to give; that decision belongs to the upstream platform.

## If you want to use it

Open an issue, or use the private channel in [`SECURITY.md`](SECURITY.md) if the
request itself is sensitive.

The decision is recorded, with its reasoning and the conditions for revisiting
it, in [`docs/maintainers/owner-actions.md`](docs/maintainers/owner-actions.md).
