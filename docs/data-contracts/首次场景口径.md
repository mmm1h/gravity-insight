# $first_scene 首次启动场景值

更新日期：2026-07-22

适用范围：TA 预置用户属性 `$first_scene`，用于首次进入小游戏的场景来源拆解。

最近验证状态以 `gravity sql status --json` 解析出的 immutable snapshot 及其 `first-scene-coverage` 为准，输出必须保留 snapshot ID 与 hash；本文定义长期语义，2026-07-04 至 2026-07-06 的查询仅作为历史证据。

## 可执行查询

```powershell
gravity sql status [--json]
gravity sql verify [--date YYYY-MM-DD] [--publish]
gravity sql query first-scene-coverage --start YYYY-MM-DDTHH:MM:SS --end YYYY-MM-DDTHH:MM:SS [--app-id ID ...]
```

结果只按 `app_id`、有值/空值状态和宿主聚合注册用户覆盖情况。返回 `partial` 时必须保留 `warnings` 和 `forbidden_claims`；`stale`、`pending_review` 或 `blocked` 时拒绝查询。只有显式 `verify --publish` 才更新最近验证证据。

## 字段本质

- `$first_scene` 是 TA 预置用户属性，不是事件属性。
- SQL 从 `default.user.properties` 取：`get_json_string(u.properties, '$.$first_scene')`。如果查询环境只支持 `get_json_object`，可用 `get_json_object(u.properties, '$.$first_scene')`。
- 不要从 `$MPLaunch` / `$MPShow` 的事件 `properties` 取 `$first_scene`；2026-07-06 的历史实测中事件侧没有该字段，全量会落到未知。
- 值域通常是 6 位数字串：`宿主前缀(2位) + 入口ID(4位)`，例如 `265001` = 红果 + 广告投放。
- 审核等特殊场景下 scene 可能为空，查询时要保留空值分组。

## 结构和判断规则

- 判断入口主含义只看后四位入口 ID；前两位只标注宿主。
- 宿主前缀和入口 ID 可任意组合，不是白名单；没列出某个宿主组合不等于该宿主没有该入口。
- 火山历史上可能出现 `04` 旧火山和 `23` 新火山；按业务问题决定合并为火山或分列。
- 遇到未列举组合，按入口 ID 的主含义解读，不要当异常值直接剔除。

## 入口 ID

| 入口 ID | 类别 |
| --- | --- |
| `5001` | 广告投放，任意宿主投放可用 `scene LIKE '__5001'` |
| `1020` | 桌面图标 |
| `1001` | 侧边栏 |
| `1022` | 游戏中心 Feed，例如 `181022` = 番茄小说 + 游戏中心 Feed |
| `3001` | 视频锚点 |
| `3010` | 直播间自然转化 |
| `3041` | 推荐流直出 |
| `2001` | 搜索 |
| `4xxx` | 分享回流，其中 `4007` 是端外分享回流 |
| `6001` | Banner |
| `6003` | Push |
| `990001` | IDE 特殊 6 位值 |
| `991020` | 手机桌面直开特殊 6 位值 |

## 常用 SQL 条件

| 目的 | 条件 |
| --- | --- |
| 红果投放 | `scene = '265001'` |
| 抖音投放 | `scene = '025001'` |
| 红果全入口 | `scene LIKE '26%'` |
| 任意宿主投放 | `scene LIKE '__5001'` |
| 拆宿主 | `SUBSTR(scene, 1, 2)` |
| 拆入口 | `SUBSTR(scene, 3, 4)` |

## 三端差异

| 端 | app_id | 复核状态 |
| --- | ---: | --- |
| 小程序版 app | `29034827` | 以最近验证证据为准；2026-07-04 至 2026-07-06 的历史分布主要有值 |
| App | `27192043` | 以最近验证证据为准 |
| iOS | `24502679` | 以最近验证证据为准 |

## 场景来源一站查询 SQL

用途：按注册日期、端、完整 scene、宿主和入口聚合 `$first_scene` 分布。执行前把 `__START_AT__` 和 `__END_AT__` 替换为北京时间左闭右开的完整窗口；保持聚合输出，不导出用户级明细。

```sql
WITH user_scene AS (
  SELECT
    app_id,
    SUBSTR(CAST(create_time AS STRING), 1, 10) AS register_date,
    COALESCE(get_json_string(properties, '$.$first_scene'), '') AS scene
  FROM default.user
  WHERE app_id IN (29034827, 27192043, 24502679)
    AND create_time >= '__START_AT__'
    AND create_time < '__END_AT__'
),
parsed AS (
  SELECT
    app_id,
    register_date,
    scene,
    SUBSTR(scene, 1, 2) AS host_prefix,
    SUBSTR(scene, 3, 4) AS entry_id
  FROM user_scene
)
SELECT
  app_id,
  CASE app_id
    WHEN 29034827 THEN '小程序版 app'
    WHEN 27192043 THEN 'App'
    WHEN 24502679 THEN 'iOS'
    ELSE '其他'
  END AS app_name,
  register_date,
  CASE WHEN scene = '' THEN '空值/未上报' ELSE '有值' END AS scene_status,
  scene,
  host_prefix,
  CASE host_prefix
    WHEN '01' THEN '今日头条'
    WHEN '02' THEN '抖音'
    WHEN '03' THEN '皮皮虾'
    WHEN '04' THEN '火山(旧)'
    WHEN '06' THEN '头条极速'
    WHEN '10' THEN '抖音极速'
    WHEN '14' THEN '番茄畅听'
    WHEN '18' THEN '番茄小说'
    WHEN '23' THEN '火山(新)'
    WHEN '25' THEN 'PC抖音'
    WHEN '26' THEN '红果'
    WHEN '27' THEN '汽水'
    WHEN '28' THEN '番茄音乐'
    WHEN '29' THEN '抖音精选'
    WHEN '99' THEN 'IDE/特殊'
    WHEN '' THEN '空值/未上报'
    ELSE '未列举宿主'
  END AS host_name,
  entry_id,
  CASE
    WHEN scene = '990001' THEN 'IDE'
    WHEN scene = '991020' THEN '手机桌面直开'
    WHEN entry_id = '5001' THEN '广告投放'
    WHEN entry_id = '1020' THEN '桌面图标'
    WHEN entry_id = '1001' THEN '侧边栏'
    WHEN entry_id = '1022' THEN '游戏中心Feed'
    WHEN entry_id = '3001' THEN '视频锚点'
    WHEN entry_id = '3010' THEN '直播间自然转化'
    WHEN entry_id = '3041' THEN '推荐流直出'
    WHEN entry_id = '2001' THEN '搜索'
    WHEN entry_id = '4007' THEN '端外分享回流'
    WHEN entry_id LIKE '4%' THEN '分享回流'
    WHEN entry_id = '6001' THEN 'Banner'
    WHEN entry_id = '6003' THEN 'Push'
    WHEN scene = '' THEN '空值/未上报'
    ELSE '未列举入口'
  END AS entry_name,
  COUNT(*) AS users
FROM parsed
GROUP BY
  app_id,
  register_date,
  scene,
  host_prefix,
  entry_id
ORDER BY register_date DESC, app_id, users DESC;
```
