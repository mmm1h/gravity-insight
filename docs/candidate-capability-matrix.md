## 维护规则

- stable 行仅保留已晋升事实和未来漂移条件，不再进入候选排期。
- draft 行必须写精确 blocker 与下一步最小证据；证据未变化时停止重试。
- 新取证原位更新同一行；完整过程进入归档，不在本页追加日期章节。
