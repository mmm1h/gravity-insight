## 使用规则

- 查当前命令、schema 和默认值：使用 reference、运行时 catalog 和 manifest。
- 查当前排期、能力证据和结构债：使用 roadmap、候选矩阵、动线台账和技术债清单。
- 只有在解释历史裁决或复核证据来源时进入本目录，并在引用时注明快照日期。
- 日常开发不向归档追加逐趟记录；新结论原位更新当前权威页，工作底稿留在 `tmp/`。
